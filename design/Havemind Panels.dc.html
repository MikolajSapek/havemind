Design notes
  • Every function in main.ts is preserved — nothing added, nothing removed. Section order matches the render order: status → send queue → conflicts → connection.
  • "Mark disconnected" shortens to Mark offline to fit 300px; Remove becomes an icon button that still arms to "Confirm remove" on first click.
  • Activity rows keep the author colour as a left rule and add a Lucide verb icon (edited / created / deleted / renamed) — colour is never the only signal.
  • All colours map to Obsidian semantic vars first (--background-secondary, --text-muted…) with the honey accent and warm tints layered as --havemind-* tokens, so third-party themes still win where it matters.
