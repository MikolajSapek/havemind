## Hard-rules summary (full version: `plan/01-zasady-i-slownik.md`)

1. TDD red-green-refactor, no exceptions.
2. The server is opaque — it never computes diff/provenance/merge.
3. Zero silent overwrites, zero trust in a client-supplied `actor_id`.
4. Secrets never go into the repo, logs, or subagent reports.
5. The agent has `ssh sapserver` access and may modify it (routine operations), but steps that
   require the `sudo` password, Tailscale Funnel, the `docker` group, or are irreversible —
   always ask the user first. A local `git commit` within the `/loop` loop — no need to ask.
   `git push` — always ask first.
6. Zero home-grown cryptography, zero Kubernetes/Portainer/Watchtower/databases "just in case".
7. All repository content (docs, comments, commit messages, plans) must be written in English.
