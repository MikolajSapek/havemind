# Closed beta recruitment copy

## Forum / Discord post

**Havemind closed beta: share an Obsidian vault on your own server**

I am looking for 10–20 desktop Obsidian users who want to test a private,
self-hosted sync plugin with one trusted collaborator. Havemind synchronises
Markdown notes and selected attachments through a server you control, shows
authorship and history, and preserves both versions when an edit conflicts.

It is for people already comfortable with Tailscale and self-hosting. It is not
a hosted sync service, does not support mobile, and does not provide end-to-end
encryption: the server operator can read synced content. Start with a fresh,
non-sensitive vault.

Interested? Reply with your desktop platform, whether you have a second device
or collaborator, and whether you can use a private Tailscale network. I will
send the beta setup guide and ask for feedback through GitHub issues.

## One-line reply to a privacy question

Havemind has no telemetry and contacts only the server the vault owner configures,
but it is not E2EE: everyone must trust that server operator with the synced
content.
