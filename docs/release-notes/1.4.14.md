# Havemind 1.4.14

After the owner types the six-digit code, the joining phone shows the Havemind
pane at once. Notes can keep arriving in the vault; the tabs and actions are
already there. Header buttons on a phone are large enough to tap.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
