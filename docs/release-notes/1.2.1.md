# Havemind 1.2.1

This release makes the connection panel more reliable and makes local test
deployments reproducible.

- The panel's keyboard listener is correctly removed when the plugin unloads.
- Release metadata is checked before publishing, preventing a mismatch between
  the plugin package, manifests and `versions.json`.
- The local test deployment now builds once, installs the same artefacts into
  both test vaults and verifies their hashes.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
