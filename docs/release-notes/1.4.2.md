# Havemind 1.4.2

Performance, aimed at phones.

- The pane no longer scans the whole vault on every repaint. The conflict scan
  is cached and refreshed when a file appears, vanishes or is renamed.
- A burst of sync events now repaints the pane once instead of dozens of times.
  Taps still respond immediately.

Together these fix the pane freezing mid-tap while sync catches up, which was
most visible on mobile.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
