# Havemind 1.10.3

1.10.2 did not reach the catalogue; this is the same release. Small fixes the owner found while joining a phone and adding agents:

- A new invitation is one box with the code, not the code plus an empty box.
- Joining with an invitation no longer asks for a server URL.
- The AI agents service no longer shows as unhealthy in Docker. Run the
  installer again to update the server.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
