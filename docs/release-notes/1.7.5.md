# Havemind 1.7.5

- Activity keeps its history when Obsidian restarts (the last 200 changes,
  stored on the device). Disconnect empties it.
- Invitations say when they expire as a time of day, and the device that is
  joining now sees that time and who invited it.
- Buttons in People and in the send queue are easier to tap on a phone.
- No server change is needed.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
