# Havemind 1.4.27

A failure to mint an access token now says why. It used to be swallowed by a
bare catch that returned an empty value, so a device would quietly stop issuing
any requests while the panel still reported the last successful cycle: the
outbox grew, the server saw no traffic, and nothing named the cause. The reason
is now logged on every failure and kept for the panel.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
