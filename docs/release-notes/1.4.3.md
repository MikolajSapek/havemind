# Havemind 1.4.3

More performance work for phones.

- Sending an attachment no longer freezes the app while it is prepared. A large
  file used to block everything for over a second on a laptop, and longer on a
  phone, so taps did nothing until it finished.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
