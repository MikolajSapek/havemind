# Havemind 1.3.0

This release makes Havemind pick up where it left off after your computer or
phone has been asleep.

- Coming back to Obsidian after the app has been in the background, or after a
  laptop has been suspended, now reconnects the real-time channel straight away.
  Before this, the periodic poll resumed on its own but the live connection sat
  idle for up to a minute first, so changes from other people arrived late even
  though the app was open again.

Nothing about syncing, history or authorship changes; a vault synced by 1.2.3
and one synced by 1.3.0 stay byte-identical.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
