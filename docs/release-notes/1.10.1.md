# Havemind 1.10.1

All five ready-made agents were run on a fresh server, and three things are
fixed:

- Agents kept working after a server update. Before, a restart left them
  all idle without a word.
- A daily summary now says who changed each note.
- An agent can update a note it wrote before (today's summary) instead of
  leaving it as it was.

Update the server too: run the installer again.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
