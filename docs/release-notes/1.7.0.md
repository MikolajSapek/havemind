# Havemind 1.7.0

- A new, quieter pane. The Status tab draws your vault as a flower: the server
  in the middle, one hexagon per device around it. Its shape is the state:
  filled when in sync, dashed when this device cannot reach the server, split
  in red where a note has two versions.
- Three tabs: Status, Activity and People. Sync now, Getting started,
  Disconnect and Reset connection are in the More options menu (the ... next
  to the tabs, or the view's own menu on a phone).
- Activity groups changes by day and names each note first, then who changed
  it.
- A device waiting for approval shows in People with its own button.
- Disconnect now asks first and names the server it stops syncing with.
- The status bar counts what waits: "3 to send", "3 waiting" when offline,
  "2 notes" in a conflict.
- Sync itself is unchanged and no server change is needed. Devices on 1.6.0
  and 1.7.0 sync normally.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
