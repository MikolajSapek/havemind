# Havemind 1.7.1

- The middle of the flower now says what sync is doing: it spins while this
  device sends, and turns green when everything is on the server. The small
  hexagon in the status bar turns green too.
- The first-run screen no longer opens with the old "Not connected" lines
  above the flower.
- On the join screen the two fields no longer run past the right edge, and
  the screen starts below the top edge.
- Sync itself is unchanged and no server change is needed.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
