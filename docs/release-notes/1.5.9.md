# Havemind 1.5.9

- The plugin's sync state file no longer grows without limit. Extra copies of
  notes it used to keep forever are no longer made, and the ones a recovery
  makes are dropped after 7 days. On one device the file shrinks from about
  577 KB to about 110 KB, which makes every save lighter, phones included.
- Old copies already stored age out on their own within 7 days.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
