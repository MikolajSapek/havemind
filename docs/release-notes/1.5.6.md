# Havemind 1.5.6

- Conflicts: resolving one can no longer lose both versions, and a conflict you
  closed with "Keep both" can still be resolved later.
- The panel says why syncing failed. Sync now and Retry run one sync instead of
  rebuilding the connection, and Reset connection asks before wiping the pairing.
- A large or slow attachment upload no longer stops a device from receiving
  changes, and one stuck change no longer blocks the rest of the vault.
- Lighter on phones: far fewer reads and writes of the plugin's data file, and
  attachments are no longer kept in memory.
- Needs the matching server update for sessions that stay signed in past 30
  days and for attachments of 22.5 to 25 MB.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
