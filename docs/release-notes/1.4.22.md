# Havemind 1.4.22

Owner-side solo edits no longer leave the synced base stuck after a push: own
echoes advance the base when disk already matches, and connect heals bases the
cursor already moved past. Empty outbox payloads are quarantined instead of
retrying forever as "Changes not sent yet".

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
