# Havemind 1.2.2

This release fixes the layout of the screens a newly installed plugin shows
before it is connected to a server.

- The chooser and the host path no longer run into the edges of the pane. Their
  blocks sat flush against the frame while the hints between them stayed inset,
  which put the text on two different left edges in a 300px sidebar.
- Those screens can now be scrolled. In a pane shorter than its content the
  overflow could not be reached at all, which left the host path's
  "I've done this, connect" button unreachable.
- The last line on each screen keeps 16px of air below it, matching every other
  screen in the panel.

Developers get a browser preview of these screens, `npm run dev:preview`, which
renders the shipping renderers and stylesheet outside Obsidian so layout that
depends on the pane's width or height can be checked before a release.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
