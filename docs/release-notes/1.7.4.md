# Havemind 1.7.4

- "Open activity" opens Havemind on the Activity tab.
- "Connect to Havemind" only shows in the command palette while you are not
  connected.
- While Havemind is retrying, Status offers "Retry now".
- Getting started no longer points at a form that is not there.
- No server change is needed.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
