# Havemind 1.10.0

- AI agents join your vault with one click: People, Add agent. Pick what it
  does (sort the inbox, write a daily summary, link related notes, turn
  meetings into tasks, digest web clips, or your own instructions) and it
  works in the background, only in the folders you allow.
- Agents are yellow, each with its own pixel icon, so you always see what an
  agent did. "Undo its changes" puts everything back.
- They think with your Claude or ChatGPT subscription, an Anthropic API key,
  or any OpenAI-compatible model (OpenRouter, OpenAI, Gemini, Ollama).
- Needs the server from this release (run the installer again). Back up
  first: the update changes the database and cannot be rolled back without
  that backup.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
