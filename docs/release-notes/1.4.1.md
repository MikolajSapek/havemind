# Havemind 1.4.1

A maintenance release. Nothing changes on screen.

- The first-run screens set their scroll box with a class instead of a `:has()`
  selector. `:has()` invalidates broadly enough that Obsidian's plugin review
  flags it as a performance risk, and these screens already know which they are.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
