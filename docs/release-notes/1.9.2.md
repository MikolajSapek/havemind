# Havemind 1.9.2

- The one-command server install now prints the line to paste. In 1.9.1 it
  could stop right before that step when run as `curl ... | bash`.
- No plugin change; existing servers and vaults are unaffected.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
