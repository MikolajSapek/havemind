# Havemind 1.5.8

- Opening the app is faster: files that have not changed since the last start
  are no longer read and hashed again.
- Each edit uploads and stores half as much, and notes of roughly 250 to 490 KiB
  that used to be refused as too large now sync.
- Large attachments send and arrive about three times faster and use far less
  memory.
- An edit made while the plugin was still starting could be lost; it no longer
  is. An attachment deleted on another device is now deleted here too.
- Old leftover data in the device's local database is cleaned up.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
