# Havemind 1.4.25

A device whose cursor the server cannot serve now re-joins itself. When the
server's sequence numbering moves underneath a client, the pull is answered with
409 CURSOR_INVALID; the client had no handling for it, so the panel showed
"Offline, the server refused the session" and the same impossible cursor was
retried forever. The cursor is now reset once and the device re-bootstraps,
converging against content already on disk without rewriting it.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
