# Havemind 1.5.4

- Fixes a device, typically a phone, that re-downloaded the whole vault every
  time Obsidian started and never received updates from other devices. Startup
  now downloads nothing unless the vault holds a local file sync does not know
  yet.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
