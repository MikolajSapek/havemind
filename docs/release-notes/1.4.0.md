# Havemind 1.4.0

Havemind now runs on phones and tablets.

- The plugin installs on Obsidian mobile. Your phone joins a vault the same way
  a laptop does: paste an invitation, read out the six digits.
- The pane is laid out for a phone. Touch targets are sized for a fingertip,
  and the layout keeps clear of the notch and the home indicator.
- On a phone the first screen offers joining only. Running the server needs
  Docker and a machine that stays awake, so that path is not shown where it
  cannot be completed; the screen still says who has to set one up.

Sync runs while Obsidian is open and in the foreground. iOS stops background
work after about 30 seconds, which applies to every sync plugin, not just this
one. Coming back to the app resumes where it left off.

Your phone needs Tailscale, on the same tailnet as the server, exactly as a
desktop does.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
