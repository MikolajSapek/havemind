# Havemind 1.4.7

- Sync recovers on its own after the network drops. A request whose connection
  died without closing used to hang indefinitely, and everything behind it
  waited too, so syncing simply stopped until the plugin was reloaded. This is
  most likely on a phone, where leaving Wi-Fi range drops a connection without
  closing it.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
