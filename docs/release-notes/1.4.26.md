# Havemind 1.4.26

Internal: the plugin kept the same truth in two places. The push producer held
its own file mappings and heads; the apply side held path owners, base hashes
and base contents separately, with nothing structural keeping the two in
agreement. When they drifted, the merge ancestor stopped matching its hash, the
three-way merge became unsatisfiable, and every later divergence turned into a
conflict copy.

Both are now one record per file with one writer per event, so that
disagreement cannot be expressed. The on-disk format is unchanged: downgrading
to an earlier build keeps working, and no migration runs on any vault.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
