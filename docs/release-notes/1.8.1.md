# Havemind 1.8.1

- The difference between versions shows only what changed, with a few lines
  around each change, in both the note history and the conflict window.
- The history window marks the version you picked, puts Restore at the top,
  and says when a version is the same as the note now.
- Both windows now match the rest of the pane: hairlines, the accent, no icon
  in the title.
- No server change is needed.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
