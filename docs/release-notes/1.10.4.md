# Havemind 1.10.4

A full review of the code, with fixes for data safety, security and the
things people ran into while joining devices and adding agents.

- Your settings, themes and snippets can no longer be wiped on every device
  by one failed read; many notes vanishing at once are held until you
  confirm; conflict copies you edited are never overwritten.
- Devices refuse changes to files Havemind never syncs.
- AI agents: no empty notes, no repeated (paid) runs, no redoing work after
  Undo; on a server with several vaults each vault keeps its own agent login.
- Joining: the six-digit code goes straight into the "wants to join" card,
  typing survives the pane refreshing, and only the owner sees Invite and
  Add agent.

Update the server too: run the installer again.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
