# Havemind 1.4.13

A new device now downloads the current vault, not the whole edit history. Ten
edits to one note become one fetch. Checking the vault from a phone no longer
mints a conflict for every empty iOS placeholder or untracked iCloud copy; two
real notes on the same path still conflict.

The self-hosted server drops superseded history once every approved device has
caught up. A phone that has not opened the vault yet blocks that cleanup.

This also includes 1.4.12, which was not published to the catalogue: join
writes only the current head of each file instead of replaying every past
revision onto disk.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
