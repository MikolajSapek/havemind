# Havemind 1.5.7

- Restore in Activity now really restores: it puts the note back to the text
  it had at that change, as a normal edit that syncs.
- A change your device cannot apply no longer stops syncing. It is set aside,
  listed in the Havemind pane with Retry and Discard, and the rest keeps going.
- The status bar shows who last edited the open note. The old author colours
  overlay is gone.
- The owner can reject a device waiting to join. People no longer shows a made-up
  "connected" state.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
