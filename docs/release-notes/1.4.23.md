# Havemind 1.4.23

Joining from a copied vault preserves divergent local notes as Conflicts
instead of silently taking the server head. Connect heal only advances the
synced base when on-disk content still matches the mapping. Open markdown
editors report dirty buffers so peer edits cannot overwrite unsaved text.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
