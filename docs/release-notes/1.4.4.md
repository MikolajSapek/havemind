# Havemind 1.4.4

- The Activity tab draws the most recent sixty changes instead of the whole
  log. Nothing is lost: the history is unchanged, and this only bounds how much
  of it the pane builds at once, which was a noticeable cost on a phone.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
