# Havemind 1.9.1

- The one-command server install now works on a fresh Linux machine: in 1.9.0
  the server could not start there. Tested from zero on Ubuntu 24.04 (arm64).
- Running the installer again after it stopped halfway finishes the setup.
- The connect form says where the installer's line goes and that the Server URL
  can stay empty for it.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
