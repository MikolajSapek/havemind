# Havemind 1.8.0

- New: "Show history of this note". Open it from the command palette or from
  a note's file menu. It lists every synced version with who made it and when;
  pick one to see how it differs from the note now, and restore it if you
  want it back. Restoring is a normal edit that syncs to everyone.
- After the update, the first connection reads the vault's change log once in
  full, so versions get their times. That first sync may take a little longer.
- No server change is needed.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
