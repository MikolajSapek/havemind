# Havemind 1.2.3

This release makes the plugin let go of its work when you turn it off.

- Disabling Havemind, or reloading it, no longer leaves a retry timer or a
  half-finished connection attempt running in the background. Before this, a
  reconnect scheduled a second or two earlier could still fire after the plugin
  had been unloaded.
- Disconnecting mid-connection now ends that attempt at once, rather than
  letting it run to completion against a vault you had already left.

Nothing about syncing, history or authorship changes; a vault synced by 1.2.2
and one synced by 1.2.3 stay byte-identical.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
