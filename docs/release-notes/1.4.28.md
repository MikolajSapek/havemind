# Havemind 1.4.28

A device joining a vault no longer re-uploads the notes it has just downloaded.
Connect-time reconcile used to push every local file it had no mapping for,
which on a joining device is all of them, so each shared note ended up in the
vault twice under two identities.

Identity is now settled by content at join time: a file whose text the vault
already holds takes that file's identity and sends nothing, while a note that
genuinely exists only on the joining device is still created as before.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
