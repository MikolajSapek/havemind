# Havemind 1.4.20

A reconnecting phone no longer dumps Havemind Conflicts or resurrected notes
onto the owner vault. Live deletes clear stale untracked and unchanged forked
copies, and a forked CREATE against a path the owner already holds is ignored.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
