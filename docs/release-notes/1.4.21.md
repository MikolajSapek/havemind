# Havemind 1.4.21

Phone joins finish without quadratic `data.json` writes, so iOS is far less
likely to kill Obsidian mid-bootstrap. An interrupted join resumes safely and
no longer pushes materialised heads back as new local creates (the source of
numbered empty "Target unknown" conflicts). Unsent outbox changes are shown
honestly, and a stale device stops blocking history compaction after 30 days.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
