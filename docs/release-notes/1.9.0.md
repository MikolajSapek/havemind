# Havemind 1.9.0

- Run your own server with one command, on Linux or a Mac:
  `curl -fsSL https://github.com/MikolajSapek/havemind/releases/latest/download/install.sh | bash`.
  It asks before installing anything, keeps the server inside your Tailscale
  network, and ends with one line to paste into Havemind.
- The connect form takes that one line; the Server URL field can stay empty.
- Step-by-step guide, Tailscale included: docs/install.md.
- Existing servers keep working; no server change is needed for this plugin.

Privacy: Havemind makes network requests only to the self-hosted server URL a
user explicitly configures for a vault. It contains no telemetry or analytics.
